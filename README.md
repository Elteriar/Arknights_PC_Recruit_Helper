# Arknights_PC_Recruit_Helper

1. Open Recruit -> Recruit Now tab
2. Click Screenshot
3. Click Scan
4. Repeat for another recruitment tab

Note: The program doesn't affect any game files; it works entirely by comparing your current screen with the tag images. If your screen resolution is significantly different from mine, you may need to replace the images in res/tags with your own.

Note 2: I wasn't able to get the Elemental and Soar tags, so the program won't recognize them and will set the background color to red. You can use a placeholder image or just ignore this.
